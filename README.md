# Skyjo Online

A free, phone-first multiplayer card game based on Skyjo's mechanics. Open a link, pick a name, and play with 2–8 friends in real time. No accounts.

> Work in progress. See [`docs/PLAN.md`](docs/PLAN.md) for the roadmap. This README gets its full how-to-play, deploy, and self-host sections as those milestones land.

## Run locally

Requires Node 22+.

```sh
npm install
npm run dev
```
